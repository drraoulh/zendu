# Zendu

Transfert d'argent **Canada → Cameroun** (web d'abord).

## Projet web

Tout le code de la V1 est dans [`web/`](./web/).

```bash
cd web
npm install
npx prisma db push
npm run dev
```

Puis ouvre http://localhost:3000

Voir [`web/README.md`](./web/README.md) pour Stripe, MoMo et le parcours démo.
